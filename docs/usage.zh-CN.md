# 使用细节

[返回 README](../README.zh-CN.md) · [English](usage.md)

## 建议菜单

- 输入三个英文字母或两个汉字后，自动查找等待 300ms，使用连续匹配；光标前为空白时不新增弹窗。候选区最多占八个显示行，小屏幕会减少；每个条目占一至三行；↑/↓ 可浏览全部结果。关闭菜单或插入后，自动建议暂停三秒。F12 不受暂停影响，支持短查询、空查询，并增加模糊匹配。
- 在命令面板选择 **Disable automatic suggestions**，可以只保留手动触发。F12 和提示词库仍然可用。
- 点击条目任意显示行只会选中，不会插入。上下选择时视窗高度保持稳定，底栏计数表示条目而不是显示行。Esc 恢复正常发送、光标移动和输入历史操作。手动打开的空结果菜单仍会拦截 Enter，不会发送草稿。
- ⭐ 是已保存的提示词，总是插入完整原始正文，预览从完整原文开头显示，保留 Markdown、缩进和换行。💬 预览实际要插入的后半段。Ctrl+S 保存完整原始片段，不只保存本次插入的后半段。
- 对话正文和表格单元格从命中字符补全到当前句子片段末尾。例如，输入 `delete` 匹配 `Do not delete the cache.` 时，插入 `delete the cache.`。代码和原生 HTML 源码从命中处补全到源码片段末尾，不补回前面的缩进或语法。预览按可用宽度折行：不超过三显示行时完整展示；超过三行时显示前两行，第三行以 `... ` 开头，保留最后一个显示行的末尾，并加 `(N lines)`。N 是添加这些标记之前的完整显示行数；调整窗口可改变 N，不改变插入内容。
- 补全替换匹配的当前词或已输入的行前缀；空查询在光标处插入。范围外的文字保持不变，包括光标右侧的其他文字；光标在词内时，会同时替换该词的剩余尾部。
- 对话命中高亮显示。保存原文仅高亮规范化后的直接连续匹配；需要去除 Markdown、解码实体或模糊搜索的命中，不强行映射到原文。完整短语的连续匹配优先于仅匹配最后一个词。接受后草稿完全相同的结果只显示一条，优先保留保存来源。后台数据更新保留当前选中项；查询或编辑范围改变时选择首项。
- 相邻条目通过交替底色区分。左右对称的标记包住整个可见列表：总共一个显示行时两侧使用 `-`；多行时首行使用 `┌` / `┐`、中间两侧使用 `│`、末行使用 `└` / `┘`。空结果、末尾填充和底栏均不绘制两侧标记。弹窗使用主题的对话框基础色，左边界与输入框左边框对齐，打开时切换主题也会同步更新颜色。
- 单行底栏左侧依次显示插入、保存、关闭，右侧在多条匹配时显示 `↑↓ 当前位置/总数`；加载或失败状态会替代计数。单条匹配不显示计数。窄屏先隐藏保存提示，再缩短其他提示；隐藏提示不禁用快捷键。文案按完整项目省略，不截成半句话或换行。切换来源不会增加说明行。
- 每条候选首行显示本地时间：💬 为消息创建时间，⭐ 为最后保存或修改时间。当天显示 `14:32`，同年往日显示 `11-14 14:32`，跨年显示 `2025-11-14 14:32`。表格片段不增加上下文标签。
- 历史按页提供结果。手动菜单区分加载中、无匹配和加载失败。失败时，已加载内容与保存提示词仍可使用；关闭并重新按 F12 打开菜单，会重试未完成的加载。
- 原生引用、斜杠命令、Shell 模式、对话框和已有选区优先于建议。插入时会保护附件标记。在 OpenTUI 0.8.4 中，光标处插入的撤销和重做各需一步，替换各需两步。

## 提示词库

用 **Save selection** 保存输入框中选中的文字，或在建议菜单中按 **Ctrl+S** 保存当前结果。保存时会展开折叠的粘贴文本，但不包含文件和图片。

在提示词库中，**Enter** 预览全文，**Ctrl+A** 新建，**Ctrl+D** 确认后删除。在列表或预览中都可用 **Ctrl+E** 编辑、**Ctrl+R** 插入。保存表单中，**Ctrl+S** 保存，**Esc** 取消。

从输入框或建议菜单保存后，直接返回输入框，并简短提示保存成功或内容重复。从提示词库新建或编辑后，显示已保存的全文。取消编辑返回发起编辑的界面。返回列表时恢复选中项，搜索框会重置；删除后选择相邻条目。

插入使用打开提示词库前记录的位置，有文字选区时会替换选中内容。如果草稿或会话变了，请关闭提示词库，在目标位置重新打开。

提示词库搜索也支持模糊匹配。列表显示可读的单行摘要，预览、编辑和插入使用原始正文。保存完全相同的正文时复用已有条目。旧记录仍可使用，但标题不再显示，也不参与搜索。没有可用输入位置时，仍可管理提示词，但不显示插入操作。

放弃未保存的修改前会要求确认。发生冲突或写入失败时，修改保留在表单中。如果另一个终端修改了同一条提示词，可以用 **Save as new** 将当前版本另存为一条记录。

## 存储与共享

提示词和自动建议开关使用 OpenCode 的本地插件存储。在同一本地配置环境和发布通道内，它们可跨项目、会话及服务器连接共享。

对话片段只留在内存中，来自当前会话中所有已完成的用户消息和助手回复。发送草稿时仍使用原有的 OpenCode 模型服务配置。请勿在提示词库中保存密钥等敏感内容。

## 生成安装包

在 `packages/occo` 中运行 `bun run pack`，安装包会写入仓库根目录的 `artifacts/`。发布检查见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
